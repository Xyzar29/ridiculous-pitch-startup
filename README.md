One sentence pitching a startup so strange it sounds like a joke — selling your home Wi-Fi network's name to the pizza place downstairs, so every neighbor hunting for a signal sees an ad — yet specific enough to see the customers (local shops) and the money (hyperlocal ads, billed per router, per month). Built for make.fun's "Ridiculous at First Glance, Real by the Second" bounty.

## Run it

```sh
node main.ts
```

The program writes exactly one line (165 characters, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). It is deterministic: every run produces byte-identical output.
